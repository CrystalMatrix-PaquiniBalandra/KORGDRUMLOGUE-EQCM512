# Free EQCM512, V.2.0 — 4バンド・パラメトリックEQ (Korg drumlogue)

**開発: CrystalMatrix aka Paquini Balandra**

**Korg drumlogue** の **logue SDK** プラットフォーム向けに特別に設計・エミュレートされた、4バンド・ステレオ・パラメトリック・イコライザーです。独立した入出力ゲインステージとパラレル・ミキシング機能（**Dry & Wet**）を備え、低域（Lows）、中低域（Low-Mids）、中高域（High-Mids）、高域（Highs）の周波数スペクトルを自在に調整できます。

---

## 主な特徴

1. **完全ステレオ処理:** クリック音やポップノイズを防ぐパラメーター・スムージング機能を搭載。
2. **4つの独立したEQバンド:** L.F.（低域）、L.M.F.（中低域）、H.M.F.（中高域）、H.F.（高域）を搭載。
3. **ゲインステージ調整:** `-20.0 dB` から `+20.0 dB` の範囲で独立して調整可能な入力ゲイン（`INPUT`）と出力ゲイン（`OUTPUT`）。
4. **パラレル・ミキシング:** エフェクト処理後の信号（`WET`）と原音（`DRY`）を個別にコントロール可能。

---

## KORG DRUMLOGUE へのインストール方法

1. このリポジトリの **Releases** セクションから、コンパイル済みのプラグインファイル（`.drmlgunit`）をダウンロードします。
2. **Korg drumlogue** を **ストレージモード（Storage Mode）** でPCにUSB接続します。
3. `.drmlgunit` ファイルを対応するエフェクトフォルダ（ビルドに応じて `Units/MasterFX` または `Units/ModFX`）にコピーします。
4. PCから安全にデバイスを取り外し、本体を再起動します。

## パラメーターとコントロール

### 入力およびミックスステージ — *drumlogue 1ページ目*

| パラメーター | 表示名 | 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **入力ゲイン** | `INPUT` | `-20.0 dB` ～ `+20.0 dB` | `0.0 dB` | EQバンドに入る前の入力信号レベルを調整します。 |
| **Wetレベル** | `WET` | `0.0` ～ `10.0` | `10.0` | イコライジングされた信号の出力音量を調整します。 |
| **Dryレベル** | `DRY` | `0.0` ～ `10.0` | `0.0` | 原音（未処理の信号）の出力音量を調整します（パラレルEQに便利です）。 |
| **出力ゲイン** | `OUTPUT` | `-20.0 dB` ～ `+20.0 dB` | `0.0 dB` | 最終的な出力レベルを制御します。 |
