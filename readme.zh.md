# Free EQCM512, V.2.0 — 4段参数均衡器 (Korg drumlogue)

**开发者：CrystalMatrix aka Paquini Balandra**

专为 **Korg drumlogue** 的 **logue SDK** 平台设计与模拟的 4 段立体声参数均衡器。它允许您在低频、中低频、中高频和高频范围内精细雕琢频谱，并配有独立的输入/输出增益级以及并联混合控制（**Dry & Wet**）。

---

## 主要特性

1. **全立体声处理：** 内置无爆音、无咔嗒声的参数平滑处理（*click-free, pop-free*）。
2. **4 个独立均衡频段：** L.F.（低频）、L.M.F.（中低频）、H.M.F.（中高频）和 H.F.（高频）。
3. **增益级控制：** 独立的输入增益（`INPUT`）和输出增益（`OUTPUT`）调节，范围为 `-20.0 dB` 至 `+20.0 dB`。
4. **并联混合：** 专用的处理后信号（`WET`）和原始干声信号（`DRY`）音量控制。

---

## 在 KORG DRUMLOGUE 上的安装方法

1. 从本仓库的 **Releases** 页面下载编译好的插件文件（`.drmlgunit`）。
2. 通过 USB 将您的 **Korg drumlogue** 以**存储模式（Storage Mode）**连接到电脑。
3. 将 `.drmlgunit` 文件复制到相应的效果器文件夹中（根据编译版本选择 `Units/MasterFX` 或 `Units/ModFX`）。
4. 安全弹出磁盘并重启合成器。

---

## 参数与控制

### 输入与混合级 — *drumlogue 第一页*

| 参数 | 标签 | 范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **输入增益** | `INPUT` | `-20.0 dB` 至 `+20.0 dB` | `0.0 dB` | 调节信号进入均衡器频段前的电平。 |
| **湿声电平** | `WET` | `0.0` 至 `10.0` | `10.0` | 经过均衡处理后的信号输出音量。 |
| **干声电平** | `DRY` | `0.0` 至 `10.0` | `0.0` | 未经处理的原始信号输出音量（适用于并联均衡）。 |
| **输出增益** | `OUTPUT` | `-20.0 dB` 至 `+20.0 dB` | `0.0 dB` | 控制最终的输出电平。 |
